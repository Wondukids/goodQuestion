# 보호자 리포트 — 프론트 연결 계약

> 2026-08-15 · `api_team` · **화면과 서버가 주고받는 값만** 정한 문서
>
> 기획 전체는 `docs/보호자_리포트_명세.md` 에 있다.
>
> ⚠️ **화면(페이지)은 따로 들어온다.** 그래서 이 문서는 레이아웃·좌표·색을 정하지 않는다.
> 시안 수치와 색 토큰을 맞추는 일은 **페이지가 들어온 뒤에** 그 페이지 기준으로 한다.
> 여기서 정하는 것은 **화면이 서버에서 무엇을 받고, 받은 값으로 무엇을 지켜야 하는가**뿐이다.

## 1. 화면이 받는 값

```ts
/** GET /api/reports/{session_id} 의 응답 */
export interface ParentReport {
  /** 'metrics_only' 면 narrative 가 null 이다 — 문장이 아직 없는 리포트 */
  status: 'metrics_only' | 'complete'
  metrics: ReportMetrics
  narrative: ReportNarrative | null
  generated_at: string
  read_at: string | null
  regenerated: number
}

export interface ReportMetrics {
  activity: {
    story_slug: string
    story_title: string
    played_at: string           // ISO
    duration_minutes: number
    completed: boolean          // false 면 중간에 그만둔 활동
    prior_activities: number    // 0 이면 이 아이의 첫 활동
  }
  counts: {
    child_utterances: number
    new_words: number
    asked_words: number
  }
  axes: Record<AxisName, Axis>
  words: {
    main: { word: string; count: number }[]
    asked: { word: string; meaning: string | null; scene_code: string }[]
    repeated: { phrase: string; count: number }[]
    new: { word: string; first_scene_code: string }[]
  }
  quotes: Quote[]               // 화면이 인용을 찾을 때 쓰는 원본 목록
}

export type AxisName =
  | '관점과공감' | '감정표현' | '생각과이유' | '결과와해결' | '상호작용'

export interface Axis {
  /** 감지된 발화 수. 0~100 이 아니다 (2절 ① 참고) */
  score: number
  parts: Record<string, number>
  context?: Record<string, number>
}

export interface Quote {
  message_id: string
  scene_code: string
  scene_label: string           // 화면에 찍을 이름. 예: "장면 3 · 들켜버린 큰 방귀"
  text: string
  elements: string[]            // 8요소 코드
}

export interface ReportNarrative {
  overall: string
  cards: SkillCard[]            // 어휘 · 표현 · 논리 순서 고정
  highlight: { quote_message_id: string; why: string } | null
  word_tip: string | null
  reason: string
  story_questions: StoryQuestion[]   // 3개
  daily_questions: DailyQuestion[]   // 3개
}

export interface SkillCard {
  axis: '어휘' | '표현' | '논리'
  summary: string
  quote_message_id: string | null    // null 이면 인용 없이 그린다
  did_well: string
  to_improve: string
}

export interface StoryQuestion {
  element: string               // 8요소 코드. 배지 이름은 elementName() 으로
  scene_code: string
  quote_message_id: string
  question: string
  fallback: string
}

export interface DailyQuestion {
  label: string                 // "내 경험과 이유" 같은 배지 글자
  question: string
  goal: string
}
```

### 인용은 글자가 아니라 id 로 온다

`quote_message_id` 는 id 다. 화면이 `metrics.quotes` 에서 찾아 쓴다.

```ts
const quote = metrics.quotes.find(q => q.message_id === card.quote_message_id)
```

서버가 「목록 밖 id 는 버린다」를 이미 하므로 **찾으면 반드시 있다.** 다만 `null` 인 경우
(LLM 이 인용을 못 고른 경우)는 있으니 그때는 인용 없이 그린다.

## 2. 화면이 지켜야 할 규칙 다섯

### ① 레이더 그래프는 그 활동 안에서만 정규화한다

`axes[*].score` 는 **0~100 이 아니라 감지된 발화 수**다. 오각형을 그릴 때
`max(모든 축의 score)` 를 100% 로 잡는다. 축이 전부 0이면(발화가 아주 적은 활동)
오각형 대신 안내 문구를 낸다.

이 숫자는 카드 문구의 “이번 활동에서 5번 나왔어요”와 **같은 값**이다 — 따로 계산하지 않는다.

### ② `status === 'metrics_only'` 면 문장이 통째로 없다

숫자·그래프·낱말 목록은 다 있고 `narrative` 만 `null` 이다. 이때는

- 역량 3카드 · 대표 발화 · 가정 연계 탭 → **빈 칸이 아니라 안내 문구**
- 「다시 만들기」를 눈에 띄게 (`POST /api/reports/{id}/regenerate`)

### ③ 첫 활동이면 「새로 쓴 낱말」의 이름이 바뀐다

`metrics.activity.prior_activities === 0` 이면 비교할 지난 활동이 없다.
숫자는 그대로 쓰되 라벨을 **「처음 만난 낱말」** 로 바꾼다.

### ④ 중간에 그만둔 활동도 화면을 낸다

`metrics.activity.completed === false`. 리포트는 만들어져 있고 값이 적을 뿐이다.
모자란 칸은 「이번엔 모인 말이 적어요」로 대신한다 — 화면을 숨기지 않는다.

### ⑤ 미읽음 표시

`read_at === null` 이면 탭 옆에 점을 찍는다. 보호자가 열면
`POST /api/reports/{session_id}/read` 를 한 번 부른다.

## 3. API

| 메서드 · 경로 | 언제 |
|---|---|
| `GET /api/children/{child_id}/reports` | 상단 활동 드롭다운을 채울 때 |
| `GET /api/reports/{session_id}` | 리포트 한 장을 그릴 때 |
| `POST /api/reports/{session_id}/read` | 보호자가 처음 열었을 때 |
| `POST /api/reports/{session_id}/regenerate` | 「다시 만들기」. **3회 넘으면 429** |

리포트 대상 아이는 선택된 아이 쿠키를 그대로 쓴다 (`requireSelectedChild()`).

## 5. 아직 안 정해진 것

| | 무엇 | 언제 정하나 |
|---|---|---|
| — | 화면 폭 · 반응형 · 색 토큰 | **페이지가 들어온 뒤** 그 페이지 기준으로 |

### ✅ M7 확정 (2026-08-15) — 미션 발화의 `scene_label`

미션(미니게임) 구간에서 나온 발화를 인용할 때는 **「미션 · <미션 이름>」** 꼴로 쓴다.

```
본 대화   "장면 3 · 들켜버린 큰 방귀"
미션      "미션 · 배 따기"      "미션 · 친구 돕기"
```

미션 이름은 `story_missions.title` 이다. 화면은 이 값을 **그대로 찍는다** — 「장면 N ·」
꼴만 온다고 가정하지 마라.
