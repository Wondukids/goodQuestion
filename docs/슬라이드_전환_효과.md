# 슬라이드 넘김(전환) 효과 정리

이미지/슬라이드를 다음 장으로 넘길 때 사용하는 전환(Transition) 효과를 트리 구조로 정리한 문서입니다.

## 전체 구조

```
슬라이드 전환 효과
├── 1. 이동 계열 (Slide / Push)
│   ├── Slide (슬라이드)
│   ├── Push (푸시)
│   ├── Cover (커버)
│   └── Uncover / Reveal (언커버)
│
├── 2. 페이드 계열 (Fade)
│   ├── Fade (페이드)
│   ├── Cross Fade / Dissolve (디졸브)
│   └── Fade Through Black / White
│
├── 3. 확대·축소 계열 (Zoom / Scale)
│   ├── Zoom In / Zoom Out
│   ├── Scale (스케일)
│   └── Zoom + Fade (줌 페이드)
│
├── 4. 회전·3D 계열 (Rotate / 3D)
│   ├── Flip (플립)
│   ├── Cube (큐브)
│   ├── Carousel (캐러셀)
│   ├── Page Curl (페이지 컬)
│   ├── Fold (폴드)
│   └── Rotate (로테이트)
│
├── 5. 마스크·모양 계열 (Mask / Shape)
│   ├── Wipe (와이프)
│   ├── Iris / Circle (아이리스)
│   ├── Split (스플릿)
│   ├── Blinds (블라인드)
│   ├── Checkerboard (체커보드)
│   └── Random Bars (랜덤 바)
│
└── 6. 특수 효과 계열 (Special)
    ├── Morph (모프)
    ├── Ken Burns (켄 번즈)
    ├── Glitch (글리치)
    ├── Pixelate / Mosaic (픽셀화)
    ├── Blur Transition (블러 전환)
    ├── Parallax (패럴랙스)
    └── Elastic / Bounce (탄성)
```

---

## 1. 이동 계열 (Slide / Push)

### 1-1. Slide (슬라이드)
- **설명**: 현재 화면이 옆으로 밀려나가고 다음 화면이 들어오는 가장 기본적인 전환
- **방향**: Left / Right / Up / Down
- **용도**: 갤러리, 캐러셀, 온보딩 화면 등 범용

### 1-2. Push (푸시)
- **설명**: 다음 화면이 현재 화면을 밀어내며 들어오는 효과 (두 화면이 붙어서 함께 이동)
- **용도**: 연속된 콘텐츠 흐름을 강조할 때

### 1-3. Cover (커버)
- **설명**: 현재 화면은 가만히 있고, 다음 화면이 위로 덮으며 들어오는 효과
- **용도**: 새 콘텐츠 등장 강조

### 1-4. Uncover / Reveal (언커버)
- **설명**: 현재 화면이 걷혀 나가면서 아래에 있던 다음 화면이 드러나는 효과 (Cover의 반대)
- **용도**: 뒤에 숨겨진 콘텐츠 공개 연출

---

## 2. 페이드 계열 (Fade)

### 2-1. Fade (페이드)
- **설명**: 현재 화면이 서서히 사라지고 다음 화면이 서서히 나타나는 효과
- **용도**: 부드럽고 차분한 전환의 기본

### 2-2. Cross Fade / Dissolve (디졸브)
- **설명**: 두 화면이 겹쳐진 상태로 투명도가 교차되며 전환
- **용도**: 사진 슬라이드쇼, 회상 장면

### 2-3. Fade Through Black / White
- **설명**: 중간에 검은색(또는 흰색) 화면을 거쳐서 전환
- **용도**: 장면(챕터) 단위의 큰 구분, 시간 경과 표현

---

## 3. 확대·축소 계열 (Zoom / Scale)

### 3-1. Zoom In / Zoom Out
- **설명**: 현재 화면이 확대되며 사라지거나, 다음 화면이 축소되며 들어오는 효과
- **용도**: 몰입감 있는 전환, 상세 화면 진입

### 3-2. Scale (스케일)
- **설명**: 다음 화면이 작은 크기에서 커지며 등장 (또는 반대)
- **용도**: 팝업형 콘텐츠, 강조 등장

### 3-3. Zoom + Fade (줌 페이드)
- **설명**: 줌과 페이드를 동시에 적용한 조합 효과
- **용도**: 세련된 느낌의 슬라이드쇼에서 가장 많이 쓰이는 조합

---

## 4. 회전·3D 계열 (Rotate / 3D)

### 4-1. Flip (플립)
- **설명**: 카드를 뒤집듯 화면이 회전하며 다음 화면으로 전환
- **방향**: 수평(Y축) / 수직(X축)
- **용도**: 카드 UI, 앞뒤 개념이 있는 콘텐츠

### 4-2. Cube (큐브)
- **설명**: 화면들이 정육면체의 면처럼 배치되어 회전하며 전환
- **용도**: 입체감 있는 갤러리, 화면 전환

### 4-3. Carousel (캐러셀)
- **설명**: 여러 슬라이드가 회전목마처럼 원형으로 돌며 전환
- **용도**: 커버플로우 스타일 갤러리

### 4-4. Page Curl (페이지 컬)
- **설명**: 책장을 넘기듯 모서리부터 말리며 넘어가는 효과
- **용도**: 전자책, 앨범, 아날로그 감성 연출

### 4-5. Fold (폴드)
- **설명**: 종이를 접듯이 화면이 접히며 전환
- **용도**: 개성 있는 전환 연출

### 4-6. Rotate (로테이트)
- **설명**: 화면 전체가 평면상에서 회전하며 전환
- **용도**: 다이내믹한 분위기 연출

---

## 5. 마스크·모양 계열 (Mask / Shape)

### 5-1. Wipe (와이프)
- **설명**: 한쪽 방향에서 닦아내듯 다음 화면이 드러나는 효과
- **방향**: 좌우 / 상하 / 대각선
- **용도**: 깔끔하고 명확한 전환

### 5-2. Iris / Circle (아이리스)
- **설명**: 원이 커지거나 작아지면서 다음 화면이 드러나는 효과
- **용도**: 특정 지점(클릭 위치 등)을 중심으로 한 전환, 레트로 연출

### 5-3. Split (스플릿)
- **설명**: 화면이 가운데에서 양쪽으로 갈라지며(또는 모이며) 전환
- **용도**: 문이 열리는 듯한 등장 연출

### 5-4. Blinds (블라인드)
- **설명**: 블라인드 커튼처럼 여러 줄로 나뉘어 순차적으로 전환
- **용도**: 리듬감 있는 전환

### 5-5. Checkerboard (체커보드)
- **설명**: 바둑판 모양의 타일이 순차적으로 뒤집히며 전환
- **용도**: 복고풍, 유희적인 연출

### 5-6. Random Bars (랜덤 바)
- **설명**: 가로/세로 막대가 무작위 순서로 나타나며 전환
- **용도**: 노이즈 느낌의 전환

---

## 6. 특수 효과 계열 (Special)

### 6-1. Morph (모프)
- **설명**: 앞 슬라이드와 뒤 슬라이드의 공통 요소가 위치·크기를 자연스럽게 이동하며 변형되는 효과 (PowerPoint의 Morph, Keynote의 Magic Move)
- **용도**: 요소 간 연속성을 강조하는 고급 전환

### 6-2. Ken Burns (켄 번즈)
- **설명**: 정지 이미지를 천천히 확대/이동시켜 영상처럼 보이게 하는 효과 (전환과 조합해 사용)
- **용도**: 사진 슬라이드쇼, 다큐멘터리 스타일

### 6-3. Glitch (글리치)
- **설명**: 화면이 지지직거리며 깨지는 노이즈와 함께 전환
- **용도**: 사이버펑크, 긴박한 분위기

### 6-4. Pixelate / Mosaic (픽셀화)
- **설명**: 화면이 픽셀 블록으로 뭉개졌다가 다음 화면으로 복원되는 효과
- **용도**: 레트로 게임 감성

### 6-5. Blur Transition (블러 전환)
- **설명**: 현재 화면이 흐려졌다가 다음 화면이 선명해지며 전환
- **용도**: 부드러운 장면 전환, 회상/꿈 연출

### 6-6. Parallax (패럴랙스)
- **설명**: 배경과 전경이 서로 다른 속도로 움직여 깊이감을 주며 전환
- **용도**: 입체감 있는 슬라이드, 스크롤형 콘텐츠

### 6-7. Elastic / Bounce (탄성)
- **설명**: 넘어간 화면이 살짝 튕기거나 늘어났다 돌아오며 정착하는 효과
- **용도**: 발랄하고 캐주얼한 UI

---

## 구현 팁 요약

```
구현 핵심
├── 시간(Duration)
│   ├── 일반 전환 — 0.3 ~ 0.6초가 적당 (너무 길면 답답함)
│   └── 강조 전환(Morph, Page Curl 등) — 0.8 ~ 1.2초까지 허용
│
├── 보간(Easing)
│   ├── 화면이 나갈 때 — ease-in
│   ├── 화면이 들어올 때 — ease-out
│   └── 탄성 효과 — elastic / bounce 커브 사용
│
├── 구현 방식
│   ├── 웹 — CSS transition/transform, Swiper.js, GSAP
│   ├── Unity — DOTween + RectTransform / CanvasGroup(alpha)
│   └── 마스크·특수 계열 — 셰이더 기반 (GL Transitions 참고)
│
└── 조합 원칙
    ├── 한 앱/프로젝트 안에서는 전환 스타일을 1~2종으로 통일
    ├── 이동 + 페이드 조합이 가장 실패 없는 기본기
    └── 화려한 효과(Glitch, Cube 등)는 포인트로만 사용
```
