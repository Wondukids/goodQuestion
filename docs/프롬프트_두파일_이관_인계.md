## 0. 배경 — 무엇을 왜 하려는가

이 서비스는 아이와 대화하는 동화 캐릭터를 만든다. 캐릭터가 무슨 말을 할지, 아이 말을
어떻게 해석할지는 **프롬프트**(LLM 에게 주는 긴 지시문)에 적혀 있고, 그 파일 6개가
`prompts/` 에 있다.

문제는 **파일 하나 안에 두 종류의 글이 섞여 산다**는 것이다.

| 층 | 무엇 | LLM 에 가나 |
| --- | --- | --- |
| 한글 층 | 왜 이렇게 정했나 · 출처 인용 · 검수 이력 | ❌ |
| 영어 층 | 실제 지시 | ⭕ |

`<!-- 보내는 것 시작 -->` 표식을 두고 `sendableBody()` 가 안쪽만 오려 보내는 방식인데,
**그 오려내기가 윈도우에서 깨져 있었다.** 정규식이 `-->\n` 을 요구하는데 CRLF 로
체크아웃되면 `-->` 뒤가 `\r` 이라 매칭이 실패하고, 「표식이 없으면 통째로」 안전장치가
발동해 한글 층까지 전부 나갔다.

**이 기획은 오려내기를 고치는 게 아니라 없앤다.** 파일을 애초에 둘로 나누면 오릴 것이
없고, 표식·정규식·줄바꿈 의존성이 함께 사라진다.

```
prompts/
  README.md                  ← 규칙 (이미 있음)
  analysis/
    보낼것.md                 ← LLM 에 나가는 것. 통째로 나간다
    해설.md                   ← 사람이 읽는 것. 한 글자도 안 나간다
  character/  child/  judge_gave_away_element/
  judge_guided_toward_target/  judge_invented_setting/
```

⚠️ **축은 언어가 아니라 역할이다.** 심판 셋은 한국어 대사를 읽고 판정하므로 나가는
쪽도 한국어다. 영어인 것은 분석·캐릭터·아이 셋뿐이고 그것도 토큰을 아끼려는 결과다.

### F. 채점을 다시 잰다 — ⛔ **사람 판단이 필요해서 멈춰 두었다**

기존 골든셋 점수는 버리기로 했다(결정 4). 분리 후 조건에서 새로 재는 것이 곧 새

#### ① 돌리면 팀 라이브 DB 에 쓴다

`.env.local` 의 `DATABASE_URL` 이 로컬이 아니라 **팀 Supabase**
(`aws-0-ap-northeast-2.pooler.supabase.com`)를 가리킨다. 골든셋 한 판은
`goldenset_runs` · `goldenset_results` 에 행을 남기므로, 그대로 돌리면 **남의 DB 에
쌓인다.**

> 참고로 검사(`vitest`)는 이 주소를 가드가 막는다(`src/llm/db/push-guard.ts`).
> 골든셋 화면은 검사가 아니라서 안 막힌다.

#### ② 돌리면 진짜 LLM 을 부른다 — 돈이 든다

정답지가 셋이고 항목 수가 이렇다.

| 정답지 | 항목 |
| --- | --- |
| `goldenset/banggui_검수전.jsonl` | 82 |
| `goldenset/banggui_말투판.jsonl` | 49 |
| `goldenset/유도/검수전.jsonl` | 73 |

한 항목이 분석 LLM 한 번이다. 어느 것을 몇 번 돌릴지가 곧 비용이다.

#### 그래서 정해야 하는 것 셋

1. **어느 DB 에 남길까** — 로컬 도커를 띄워 거기 남길까, 팀 DB 에 남길까.
2. **어느 정답지로 잴까** — 셋 다인가, `banggui_검수전` 하나인가.
3. **`element_criteria` 를 켤까** — 기본은 **꺼짐**이다
   (`src/llm/service/goldenset.ts` 의 `기준_포함`). 파이썬이 이 조건(빈 값)으로
   기준선을 재 왔고, 그 16문장은 아직 **검수받지 않은 AI 초안**이다. 한 번에 하나만
   바꾸려면 끈 채로 먼저 재는 편이 맞다.

#### 돌리는 법

관리 화면 `/goldenset` 에서 돌린다 (`src/app/(admin)/goldenset/actions.ts` 의
`runGoldensetAction`). CLI 진입점은 없다.

```bash
pnpm dev          # 그다음 브라우저에서 /goldenset
```

#### 다 돌린 뒤

새 지문이 함께 박제된다. **이때부터 지문이 OS 무관하게 고정된다** — `.gitattributes`

(`tests/prompt-lab.test.ts` 의 소스 훑기와 같은 원리 — 주석에 적어도 빨개진다.)

⚠️ 셋 다 **「태그는 양쪽에 있는데 뜻이 어긋난 것」은 못 잡는다.** 검사 자신이 그것을
단언으로 적어 두었다(`expect(태그('[E-A] 하늘은 파랗다')).toEqual(태그('[E-A] 하늘은 빨갛다'))`).
그건 사람이 두 파일을 나란히 놓고 읽어야 한다.

① 에는 **32쌍 고정 단언**이 있다. 규칙을 더하거나 지우면 빨개진다 — 의도한 것인지
확인하고 숫자를 고쳐라.
