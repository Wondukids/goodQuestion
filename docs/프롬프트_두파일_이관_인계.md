## 0. 배경 — 무엇을 왜 하려는가

이 서비스는 아이와 대화하는 동화 캐릭터를 만든다. 캐릭터가 무슨 말을 할지, 아이 말을
어떻게 해석할지는 **프롬프트**(LLM 에게 주는 긴 지시문)에 적혀 있고, 그 파일 6개가
`prompts/` 에 있다.

문제는 **파일 하나 안에 두 종류의 글이 섞여 산다**는 것이다.

| 층 | 무엇 | LLM 에 가나 |
| --- | --- | --- |
| 한글 층 | 왜 이렇게 정했나 · 출처 인용 · 검수 이력 | ❌ |
| 영어 층 | 실제 지시 | ⭕ |

`<!-- 보내는 것 시작 -->` 표식을 두고 `sendableBody()` 가 안쪽만 오려 보내는 방식인데,
**그 오려내기가 윈도우에서 깨져 있었다.** 정규식이 `-->\n` 을 요구하는데 CRLF 로
체크아웃되면 `-->` 뒤가 `\r` 이라 매칭이 실패하고, 「표식이 없으면 통째로」 안전장치가
발동해 한글 층까지 전부 나갔다.

**이 기획은 오려내기를 고치는 게 아니라 없앤다.** 파일을 애초에 둘로 나누면 오릴 것이
없고, 표식·정규식·줄바꿈 의존성이 함께 사라진다.

```
prompts/
  README.md                  ← 규칙 (이미 있음)
  analysis/
    보낼것.md                 ← LLM 에 나가는 것. 통째로 나간다
    해설.md                   ← 사람이 읽는 것. 한 글자도 안 나간다
  character/  child/  judge_gave_away_element/
  judge_guided_toward_target/  judge_invented_setting/
```

⚠️ **축은 언어가 아니라 역할이다.** 심판 셋은 한국어 대사를 읽고 판정하므로 나가는
쪽도 한국어다. 영어인 것은 분석·캐릭터·아이 셋뿐이고 그것도 토큰을 아끼려는 결과다.

## 3. 남은 순서 — B ~ F

### B. 줄바꿈을 통일한다

⚠️ **목적이 「오려내기」가 아니라 「지문」이다.** 오려내기는 어차피 D 에서 사라진다.
`fileDigest()` 가 원문 바이트의 sha256 이라 같은 커밋인데 OS 마다 지문이 갈리는 것이
진짜 문제다 — `prompts/*.md` 6개와 `goldenset/*.jsonl` 3개 전부.

⛔ **`git add --renormalize` 는 아무것도 하지 않는다.** 인덱스가 이미 LF 라
정규화할 것이 없다(`git ls-files --eol` 로 확인 — `i/lf w/crlf`). 바꿔야 하는 것은
작업 트리다.

```bash
git rm --cached -r . -q
git reset --hard
```

- ⛔ `reset --hard` 는 미커밋 변경을 날린다. **먼저 커밋할 것.**
- 추적 텍스트 약 330개가 CRLF→LF 로 바뀐다. **커밋되는 변경은 0건**이고 디스크
  바이트만 바뀐다.
- 바이너리 178개는 안 건드린다(전수 검증 완료 — `tests/fixtures/*.jsonl.gz` 가
  `*.jsonl` 규칙에 걸릴 뻔한 것 포함). `*.ps1` 은 CRLF 유지.
- 검증: 지문이 리눅스 값과 일치 (`analysis.md` → `307600ac…`), 위 검사 7개가 초록.

### C. 파일을 나눈다 — 글자는 그대로

6개 파일 → 폴더 6개 × 2파일. 표식 기준으로 잘라 **옮기기만 한다.**

⛔ **문장을 다듬지 마라.** 자리 옮기기와 내용 고치기를 같은 걸음에 하면, 나중에 점수가
흔들렸을 때 「자리를 옮겨서」인지 「글자를 고쳐서」인지 못 가른다.

- 검증: 두 파일을 도로 이으면 원본과 같은가.
- 🔴 **폴더 이름 = 지금 파일 이름(확장자 뺀 것).** 바꾸면 안 된다 — 4절 참고.
- ⚠️ **심판 셋은 표식이 없다.** 층이 하나라 어디서 자를지 사람이 판단해야 한다.
  특히 `judge_gave_away_element.md` 는 사람용 인용이 섞여 있다(5절 참고).

### D. 코드를 전환한다

`sendableBody` 삭제 · `read()` 가 `<이름>/보낼것.md` 를 연다 · 틀 파싱 제거(결정 2) ·
지문 경로 3곳 · 작업대 목록이 파일 대신 폴더를 센다.

`src/app/api/` 와 `src/llm/controller/` 전체에서 `prompt` 가 **한 곳도 안 나온다.**

즉 **DB 접근 패턴도 그대로다.** 바뀌는 것은 `chooseBody` → `read()` 안의
**파일시스템 경로 한 줄**뿐이다.
